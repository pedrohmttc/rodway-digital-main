🚢 Rodway Digital

Projeto acadêmico de **prototipagem e design de interface**, desenvolvido com foco na criação de uma plataforma web para **gestão e reserva de transporte fluvial**.

---

 Sobre o Projeto

O Rodway Digital é um protótipo de sistema web que simula uma solução digital para centralizar informações de rotas, horários e reservas no transporte fluvial, com foco em **usabilidade, organização da informação e experiência do usuário**.

Este projeto não possui backend ou persistência de dados, sendo voltado exclusivamente para **design, estruturação de telas e navegação**.

---

 Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript  

---

 Objetivo Acadêmico

- Praticar **prototipagem de interfaces web**
- Aplicar conceitos de **design responsivo**
- Estruturar páginas e fluxos de navegação
- Desenvolver um protótipo funcional utilizando apenas tecnologias frontend
